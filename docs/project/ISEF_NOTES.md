## 核心思想（对我们项目的启发）

### 问题背景
- 折纸/连杆机构 = 由面片（连杆）+ 折痕（铰链）组成的多体系统
- 构型空间 = 所有可能折叠角度组合构成的高维空间
- 传统方法：逐一追踪单一路径，或无法穷尽所有可能性 → 只能得到一条折叠路径

### 创新方法
- **MCMC（马尔可夫链蒙特卡洛）随机游走**：在构型空间中采样，单次运算同步评估所有折叠可能性
- 成功预测瓢虫翅膀等已知折叠结构（自然界的折叠模式）
- 核心价值：不是"预设一条路径"，而是**探索整个合法构型空间**，找到物理可行的折叠方式

### 与我们模拟器的对应关系

| ISEF 项目 | 我们的模拟器 |
|---|---|
| 构型空间（所有折叠角度组合） | 每步的折痕角度数组 creaseAngles |
| MCMC 在合法构型间随机游走 | 分步折叠在合法完成态之间推进 |
| 能量/约束判断合法性 | 穿模检测（三角形相交 = 非法） |
| 找到物理可行的折叠路径 | 步骤完成态 = 合法构型（穿模=0） |

### 已借鉴的落地（本次实现）
1. **分步折叠**：不在折痕角度空间线性插值（中间态几何非法 → 严重穿模），
   而是在**两个合法完成态之间做顶点插值**（MCMC 在合法构型间移动的简化版）
   → 验证：顶点插值动画穿模 = 0（所有模型），折痕渐进动画 crane 最差 534
2. **步骤顺序**：按真实折纸逻辑分组（角度族：对角线→中心线→斜折→细节），
   而非按长度 → 步骤数 39→20，语义清晰

### 未来可借鉴（未实现）
1. **真正的 MCMC 求解器**：对每个折叠进度，用 Metropolis-Hastings 在构型空间采样
   合法构型，替代"预设步骤顺序"→ 可处理非 flat-foldable 的复杂模型
2. **能量函数**：面片穿透惩罚 + 折痕角度约束 → 找到自然折叠路径
3. **多路径探索**：同一 CP 可折叠成多种形态时，枚举所有可行结果

## 技术备注
- 该项目用 Julia（科学计算语言），核心是统计采样而非确定性几何
- 我们的场景（新手教学、实时交互）用简化版足够：合法构型间插值已能达到穿模=0
- 完整 MCMC 求解对实时 Web 太重，但"合法构型间移动"的思想已落地
