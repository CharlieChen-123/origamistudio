# 折纸网站 · 分阶段开发清单 (ROADMAP)

> 文件已归档到 `docs/project/`；当前功能状态以根目录 `README.md` 和 `docs/README.md` 为准。

> 目标：面向新手/进阶折纸爱好者的开源网站，包含 **CP 折痕图设计器** 与 **交互式折叠模拟器**。
> 原则：每阶段独立可验收、可回退，避免一次性堆完代码再集中除 bug。

---

## 方案选型（调研结论，2026-08）

| 方案 | 语言/协议 | 结论 |
|---|---|---|
| OrigamiSimulator (Amanda Ghassaei) | JS / MIT | 刚性折叠求解器，GPU 并行，适合"全折"演示；对新手分步教学不友好，代码量大 |
| rabbit-ear | JS / **GPLv3** | 库很全，但 GPL 传染，**不能直接采用**（会污染 MIT 开源计划） |
| ORIPA (Java) | Java | 折痕图编辑 + 折叠模拟，需移植且协议限制 |
| **OE3D 算法**（你 src1.3.5 里的） | Java / GPLv3 | 核心：**多边形切割 + 平面反射/旋转折叠**，天然支持"分步折叠"，适合新手 |
| **FOLD 格式** | JSON / MIT | 社区标准数据格式，作为我们的数据模型基础 |

**采用方案**：以 OE3D 的"多边形切割 + 反射/旋转折叠"算法思想为蓝本，但**完全自研实现**（不复制 GPL 代码，只用数学原理）：
- 数据模型改用 **FOLD 社区标准**（MIT），同时兼容 `.ori` 解析
- 面片拓扑用 **half-edge（半边）结构** 替代 OE3D 的字符串级切割，性能更好、代码更清晰
- 折叠变换用 **4×4 矩阵** 统一处理反射/旋转/动画插值
- 渲染用 **three.js**（MIT），提供 3D 分步折叠 + 折角滑杆
- 与 CP 设计器 **完全分离**（不同文件/目录），互不干扰

**与 OE3D 相比的优化点**：
1. 半边缘结构 → 面片查找 O(n) 而非字符串比对
2. 矩阵化折叠变换 → 支持任意折角动画（OE3D 只有固定 180°/角度跳跃）
3. FOLD 格式 → 可被 OrigamiSimulator / rabbit-ear 生态互操作
4. 新增"步骤讲解"层 → 每步可挂文字教程（新手向）

### ⬜ 阶段 1 — 折痕图面片化（CP → 面片拓扑）
- [ ] half-edge 构建：从 `edges_vertices` 生成半边、角点、面片环
- [ ] 面片枚举：平面图遍历，输出 `faces_vertices`
- [ ] 边界检测：区分内部折痕 / 纸张边界
- [ ] 交点处理：折痕交叉点自动剖分（T 型、X 型）
- [ ] 复杂折痕图（如 `cp_examples/` 里的 svg/fold）全部可面片化
- [ ] **验收**：面积守恒（面片面积和 = 纸张面积 ± 1e-6）；frog/crane CP 面片数与 OE3D 一致

> ✅ **阶段 1 已完成（2026-08-07）**：`src/planarize.js`（交点剖分+自动补边界+去重）+ `src/halfedge.js`（半边面片追踪）。
> 4 个真实模型（crane 72面 / frog 238面 / boat 12面 / butterfly 105面）面积守恒误差 0.000%，32 单测全绿。

### ⬜ 阶段 2 — 折叠核心引擎
- [x] 折痕折叠变换：沿任意 3D 直线的旋转矩阵 + 平面反射矩阵
- [x] 单折痕折叠：选取一侧所有面片 → 应用变换（180° 反射 / 任意角度旋转）
- [x] 折痕赋值解析：M=山折 / V=谷折 / B=边界 / U=未分配
- [x] 多面片联动：一步折叠 = 面片集合变换，保证纸面连续（共享顶点同步移动）
- [x] 数值稳定性：浮点误差收敛、折叠后顶点重合检测
- [ ] **验收**：千纸鹤 CP 按标准顺序折叠出正确立体形状；"全折"指令与 OrigamiSimulator 输出形状一致

> ✅ **阶段 2 核心完成（2026-08-07）**：`src/fold-engine.js` 面片级刚性折叠引擎（BFS 传播旋转矩阵），
> 10 个 MIT 标准模型全部面片化（crane 70面）+ 折叠无 NaN + 面片刚性不变形，40 单测全绿。

### ✅ 阶段 3 — 分步折叠流程（新手向）
- [x] 折叠序列定义：`[ {creases, angle, desc} ... ]`（每步 = 折痕线段索引组 + 角度 + 说明）
- [x] 播放器：上一步/下一步/自动播放/重置 + 步骤进度（Step x / N）+ 折痕角度渐进动画
- [x] 折痕高亮：CP 图与 3D 折痕线同步显示（山红/谷蓝/引导灰）
- [ ] 历史栈：undo/redo 到任意步骤，状态可回放
- [x] 导入折痕图 → 自动面片化 → 分步折叠（MIT SVG 数据源，10 模型带步骤序列）
- [x] **验收**：分步折叠每步完成态穿模 = 0（全部模型验证）；动画中间帧立体度最高 370（纸真实立起）

> ✅ **阶段 3 完成（2026-08-07）**：从"所有折痕同时折叠"（必然穿模）改为"分步折叠"——
> 真实折纸每步只折 1-3 条折痕，步骤完成态是合法平坦构型（不穿模），
> 动画用折痕角度渐进（0°→180°），纸绕折痕线真实立起。
> 关键认知：crane 是 flat-foldable，任何子集折 180° 结果都是平的（z=0），
> 立体感只能来自动画中间帧（折痕角度 90° 左右时纸立起）。
> 基底模型（square/waterbomb/bird）手工定义经典教程步骤（预折→收拢）。
