# Documentation Index

This directory holds product notes, development plans, and future-feature proposals. The root `README.md` is the quick start for users. Third-party notices remain at the project root so they are easy to find when publishing.

## Product and feature notes

- [Complete crane and reusable templates](complete-crane-templates.md): 33-step lesson, supported compound actions, authoring, and validation.

- [Square-base solver and dash validation](square-base-solver-validation.md): implemented motion, six continuation steps, research sources, and regression checks.
- [Action editor validation](action-editor-validation.md): research, tests, backups, and the limits of the Flat Crane and retired seam experiment.
- [Accurate crane square-base plan](crane-square-base-plan.md): target geometry, material layers, animation options, and acceptance checks.

- [Step-by-step folding tutorials](folding-steps.md): authoring flow, portable format, and limits for Fold Lab's built-in tutorial editor.
- [Third-party code and model credits](../THIRD_PARTY_NOTICES.md): sources and licenses for OrigamiSimulator, dependencies, and example patterns.

## Project records

- [Roadmap](project/ROADMAP.md): staged goals and technical decisions. This is a historical record in Chinese.
- [Open-source publishing checklist](project/OPENSOURCE_CHECKLIST.md): a historical Chinese checklist; the root `README.md` has the current startup and testing instructions.
- [ISEF research notes](project/ISEF_NOTES.md): background research about origami configuration-space algorithms, kept in Chinese as an archived research note.

## Development references

- [Tools directory](../tools/README.md): scripts for generating the simulator page, processing models, and running a local server.
- [OrigamiSimulator localization notes](../vendor/origamisimulator/LOCAL_NOTES.md): the upstream copy, local changes, and running notes.

## Recommended reading order

1. Read the root `README.md`, start the application, and import an SVG pattern.
2. Read the [step-by-step folding tutorials](folding-steps.md) to author and share an instructional sequence.
3. For further development, read the [roadmap](project/ROADMAP.md) and `tools/README.md`.
4. Before publishing, review the [third-party credits](../THIRD_PARTY_NOTICES.md) and the publishing checklist.
